# Работа с GitHub Actions

Репозиторий содержит:
- библиотеку для работы с книгами
- unit-тесты
- GitHub Actions workflows:
  - flake8 (проверка стиля)
  - unittest (автотесты для ветки dev)

## Структура проекта

- src/library.py — основной код
- tests/test_library.py — тесты
- workflows — CI-пайплайны
